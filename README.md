# 作業書作成支援ツールV2

動画や画像から、簡単に手順書（作業書・マニュアル）を作成できるブラウザベースのツールです。
直感的な操作で画像をキャプチャし、図形やテキストで注釈を加え、リッチテキストで説明文を記述することができます。作成したデータはPDF印刷やJSONファイルとして保存可能です。

## 🌟 主な機能

* **メディアの取り込み**: 動画ファイルからのフレームキャプチャ、または画像ファイルの直接アップロードに対応。
* **充実した注釈ツール**: 画像上に「丸（囲み）」「矢印」「テキストラベル」「番号スタンプ」を追加可能。
* **画像編集機能**: 取り込んだ画像の拡大・縮小・回転・ドラッグ移動に対応。
* **リッチテキストエディタ**: 手順の説明文は、文字の太さ、色（赤・青・黒）、サイズを変更可能。
* **ステップ管理**: 複数選択での一括移動、ステップの並び替え、削除機能。
* **保存と出力**: 作成したデータのローカル保存（JSON形式）と読み込み、A4サイズに最適化された印刷・PDF出力。

## 📖 使い方

### 1. 動画や画像の追加
作業の元となるメディアを読み込みます。

* **動画からキャプチャする場合**:
  1. 左側のパネルから「動画を選択」をクリックし、動画ファイルを読み込みます。
  2. 動画を再生・シークし、必要な場面で「キャプチャ」ボタンを押します。
* **画像を追加する場合**:
  1. 左側パネルの「画像を追加」エリアをクリック、または画像ファイルをドラッグ＆ドロップします。
  2. 複数の画像を一度に追加することも可能です。

### 2. ステップの選択と編集
追加された画像は、画面右側に「ステップ」として追加されます。

* 編集したいステップを**クリックして選択**します（選択されたステップは青枠でハイライトされます）。
* 画像上をドラッグすると、表示位置の調整が可能です。
* 左側の「編集ツール」から、画像の「回転」「拡大」「縮小」「リセット」が行えます。

### 3. 注釈（図形・テキスト）の追加
選択したステップの画像に注釈を追加して、作業のポイントをわかりやすくします。

1. 左側の「編集ツール」から追加したい注釈のアイコンをクリックします。
   * 🔴 **丸**: 強調したい箇所を囲みます。
   * ➡️ **矢印**: 動きや方向を示します。
   * 🔤 **テキスト**: 任意のテキストを画像上に配置します。
   * 🔢 **番号**: 手順の順番などを示す番号スタンプを配置します。
2. 画像上の追加したい場所をクリックすると注釈が配置されます。

**【注釈の編集】**
* **移動**: 注釈をドラッグして移動します。
* **変形・サイズ変更**: 注釈をクリックして選択すると表示される青いハンドル（点）をドラッグして、サイズや向きを調整します。
* **線の太さ**: 注釈を選択した状態で「太」「細」ボタンを押します。
* **文字の変更**: テキストラベルや番号スタンプを**ダブルクリック**すると、内容を変更できます。テキストラベルは選択後に「赤字」ボタンで文字色を赤に変更可能です。
* **削除**: 注釈を選択して「ゴミ箱」アイコンをクリックします。

### 4. 説明文の入力
各ステップの右側にあるテキストエリアに、作業の手順やポイントを入力します。

* 上部のツールバーを使用して、文字の「太字(B)」「色（赤・青・黒）」「サイズ（小・中・大）」を変更できます。

### 5. 保存と印刷（PDF化）
* **データの保存**: 画面右上のファイル名入力欄に名前を付け、「保存」ボタンを押すとデータがJSON形式でダウンロードされます。
* **データの読み込み**: 「読込」ボタンから、保存したJSONファイルを選択して続きから作業を再開できます。
* **印刷 / PDF**: 「印刷 / PDF」ボタンを押すと、ブラウザの印刷ダイアログが開きます。PDFとして保存するか、プリンターで印刷してください（※A4サイズ、余白「なし」または「最小」を推奨）。

## 💻 動作環境
本ツールはブラウザ上で動作します。HTMLファイルをダブルクリックして、最新のWebブラウザ（Google Chrome, Microsoft Edge, Safari など）で開いてご使用ください。
（サーバーへのアップロード等は不要で、オフラインでも基本的な動作が可能です）
